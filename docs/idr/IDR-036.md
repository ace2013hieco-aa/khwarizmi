## Context

Hermes' ratified falsification terminus is **REFUTED** (v6 §10.1/§10.2, "any →
REFUTED" on decisive falsification: failed pre-registered test, replication
failure, or a validity/leakage bug in the supporting pipeline). On this
baseline the Evidence Ladder itself is a Phase 0 placeholder — no evidence
table, no EvidenceRepository (authority map, `docs/idr/hermes_v6_authority_evidence_map.md`).
There is therefore **no structured answer to why a hypothesis failed** and no
deterministic mapping from the cause to what may be proposed next — every
reject/patch/pivot decision would be ad hoc, which is exactly the silent-pivot
risk the surviving-ideas review's Chain A prohibits.

The external framework (`hermes_surviving_ideas_application_framework.md`,
Q-05 — ADOPT NARROWLY) proposed a five-class taxonomy
(HARD_AXIOM_VIOLATION, IMPLEMENTATION_FAILURE, ENVIRONMENT_MISMATCH,
RESOURCE_CONSTRAINT, FRAMING_ERROR) stored on "the existing FALSIFIED record".
The repository reconciliation (`hermes_surviving_ideas_repo_reconciliation.md`)
falsified that premise: **FALSIFIED does not exist anywhere in the tree**, the
ladder terminus is REFUTED, the ladder has no code, and no falsification
record exists to extend. "Axiom" has no Hermes carrier (0 hits in src and in
v6). Q-05 therefore lands as a **pure, deterministic classification substrate**
in the repository's established manual-proof-first pattern (`claims.py`,
`thesis.py`, `programs.py`): it defines the record shape the future REFUTED
write path will persist, classifies it, and computes the permitted-proposal
set — without building the ladder, without a state machine, without a write
path, and without any authority.

## Decision

**Adopt the Q-05 failure-classification substrate, its six-class taxonomy, and
its deterministic action map as architecture. No authority moves.**

### D1 — The taxonomy (revised from the framework's five)

| FailureClass | Hermes-native meaning | Required citation (deterministic) |
|---|---|---|
| `DECLARED_CONSTRAINT_VIOLATION` (renamed from HARD_AXIOM_VIOLATION) | The falsifying evidence contradicts a **declared constraint**: the hypothesis's `falsification_condition`, a program `methodology_constraint`, or a ScopeBrief constraint. The claim is invalid within this declared frame. | `constraint_ref` resolving to a declared constraint of the cited program/brief; `evidence_refs` ⊆ record evidence |
| `IMPLEMENTATION_FAILURE` | The underlying claim may remain viable; the **tested mechanism failed** — §10.2's "validity/leakage bug in the supporting pipeline", failed BacktestResult/Replication/leakage Validation, `EXPLORATORY_DRIFT` (spec drift, §11.1). | `failed_mechanism_ref` resolving to a **prediction/observable** of the program (never the claim itself); `evidence_refs` ⊆ record evidence |
| `ENVIRONMENT_MISMATCH` | The mechanism fails in the tested **regime** and may hold in another declared regime (ICSS-v1 axis; `regime` context dimension). | `regime_ref` resolving to a declared regime; `evidence_refs` ⊆ record evidence |
| `RESOURCE_CONSTRAINT` | The evidence primarily demonstrates a **measured resource deficit**, not a scientific contradiction. | structured `resource_gap` with `observed < required` (numeric); `evidence_refs` ⊆ record evidence |
| `FRAMING_ERROR` | The problem definition/question itself is wrong or malformed — the fault is in the **ScopeBrief**, not the mechanism. | `scope_brief_ref` + `scope_brief_field` resolving to a field of the frozen brief; `evidence_refs` ⊆ record evidence |
| `UNKNOWN` | The evidence does not permit an honest single classification. | none (evidence refs optional) |

Exactly-one primary class + optional validated `contributing_factors` (same
enum, disjoint from primary). `UNKNOWN` is first-class — a wrong forced
classification is worse than an explicit unresolved result. `MULTI_FACTOR` is
**not** a class (a catch-all hides the primary and breaks action routing).

### D2 — The deterministic action map (proposal categories; never executed)

| FailureClass | Permitted-action set |
|---|---|
| `DECLARED_CONSTRAINT_VIOLATION` | {REJECT_BRANCH, REVIEW_DOWNSTREAM_IMPACT} |
| `IMPLEMENTATION_FAILURE` | {PROPOSE_MECHANISM_SUBSTITUTION} |
| `ENVIRONMENT_MISMATCH` | {PROPOSE_SCOPE_NARROWING} |
| `RESOURCE_CONSTRAINT` | {PARK_FOR_RESOURCE_REVIEW} |
| `FRAMING_ERROR` | {ROUTE_TO_SCOPE_REVIEW} |
| `UNKNOWN` | {ESCALATE_TO_DIRECTOR} |

The actions are Hermes-native **proposal categories**, mapped to existing
routes: REJECT_BRANCH → `ABANDON`/`EVIDENCE_TRANSITION` (human-gated for
pre-registered hypotheses, v6 §9.2); PROPOSE_MECHANISM_SUBSTITUTION → Director
`PROPOSE_RESEARCH_PROGRAM` (new program version — never auto-created);
PROPOSE_SCOPE_NARROWING → new ScopeBrief version (S16 amendment);
ROUTE_TO_SCOPE_REVIEW → ScopeBrief revision authority (S16, human);
PARK_FOR_RESOURCE_REVIEW / ESCALATE_TO_DIRECTOR → Director review only. The
vocabulary contains **no creation/mutation actions** — the mapping computes
permissions; executing any of them still requires the existing authorized
pathway.

### D3 — Authority boundary (enforced by construction, not by convention)

MAY (all inside the substrate): propose a class; cite
evidence/constraint/mechanism/regime/resource-gap/scope-field; deterministically
validate citations; deterministically map to the permitted-action set; derive
`requires_human_confirmation` (True iff FRAMING_ERROR); surface the result for
review.

MUST NOT: create a hypothesis; create a program; create a task; retract a
branch; revise ScopeBrief; change ladder/evidence state; bypass a gate; alter
budgets; change scheduler priority; override the Director; bypass the Intent
Gateway. The substrate has no SQL, no repository/gateway/event imports, no
filesystem/network access — an ADMITTED classification is advisory metadata,
and every downstream action still passes the existing authorized pathway.

### D4 — Model boundary

LLM/model-assisted: propose `failure_class`, `explanation`, `evidence_refs`,
the class-specific citations, `contributing_factors`, `proposed_by`,
`classifier_version`. Deterministic (code, final): closed enum values;
schema/types; required-citation-per-class; citation resolution (injected
project-scoped resolvers); `evidence_refs ⊆ record.falsifying_evidence_refs`;
`resource_gap.observed < required`; factor disjointness; the action map;
permission checks; identity + versioning; serialization; replay determinism.
The LLM is never the authority on whether a permitted action occurs.

### D5 — Versioning and phase

The taxonomy is schema-versioned (`FAILURE_CLASS_SCHEMA_VERSION = "1"`) and
every draft carries a required `classifier_version`; both enter the
content-derived `classification_id`. Reclassification under a new version is a
NEW derived record — historical truth is never mutated. Persistence is
deferred (manual-proof-first, v6 §29.2 rule 7): the classification attaches to
the future REFUTED write path as a metadata field + `provenance_edges`
citation edges when the Evidence Ladder lands (P2 roadmap). The substrate
defines that record shape now (`FalsificationRecord`). **Roadmap correction
(IDR-037, 2026-08-15):** the Evidence Ladder remains deferred, but Q-05
advisory persistence was implemented EARLY through the existing artifact
store as preparatory infrastructure, so the future REFUTED write path consumes
an existing, ratified contract. The architecture has not been structurally
expanded (no new tables/authorities), but the implementation SEQUENCE
changed — recorded here honestly.

## Rationale

1. **The gap is real and repo-verified.** No failure taxonomy, no action
   mapping, and no falsification record exist anywhere in the tree (the ladder
   is a placeholder). The framework's "extend FALSIFIED" was impossible; the
   corrected substrate-first premise is the same manual-proof-first pattern
   CONTRA P7 used (`claims.py` substrate → IDR-026/027 write path).
2. **Small, subordinate, and authority-free.** The smallest honest model is a
   validator result — not a new artifact family (`FailureAnalysis`,
   `FailureModeArtifact`, `HypothesisFailureObject`, `FailureState` are all
   rejected), not a new intent, not a new table, not a parallel state machine.
   The taxonomy classifies a falsification record; it holds no state and
   executes nothing, so it cannot become a second epistemic authority or a
   silent pivot.
3. **Hermes-native citation targets.** Every class cites something Hermes
   actually has: declared constraints (program/brief), predictions/observables,
   the regime axis, a measurable resource gap, or a frozen ScopeBrief field.
   "Axiom" has no carrier, so the class was renamed; UNKNOWN keeps the honest
   fallback.
4. **FRAMING_ERROR is deliberately the most restricted class.** It requires a
   specific ScopeBrief field citation, derives `requires_human_confirmation`,
   and permits only ROUTE_TO_SCOPE_REVIEW — no agent, LLM or otherwise, can
   rewrite the brief through this mechanism.
5. **Determinism + versioning protect history.** Same inputs ⇒ same output;
   classification_id binds (schema, classifier, content), so a reclassification
   is a new derived record and replay is byte-stable.
