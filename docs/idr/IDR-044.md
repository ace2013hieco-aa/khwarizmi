# IDR-044: the regime-axis registry substrate (`src/hermes/research/regimes.py`)

**Status:** Decided + implemented + tested (Step 4 / S-R1; branch `step-4/s-r1`, local-only)
**Date:** 2026-09-27
**Decides for:** The closed, versioned regime-axis registry the claims path has dereference-assumed since the P7 substrate and the failure-classification path has deferred fail-closed since IDR-037 (D5).

## Context

The v3/v6 baseline ratifies the **ICSS-v1 structural-break axis** as the day-one regime taxonomy (recorded via `regime_taxonomy_version` on spec and manifest), and the claims path has always assumed a regime dereference carrier: `regime` ∈ `CONTEXT_DIMENSIONS` and `DEREFERENCE_DIMENSIONS` (`src/hermes/research/claims.py:94-104`), with the P7 fixtures resolving the tag form `ICSS-v1:low-vol`. But the axis store itself was never built — every downstream surface defers it fail-closed: the failure-classification write path refuses `ENVIRONMENT_MISMATCH` "until the regime axis (ICSS-v1) lands" (`src/hermes/persistence/failure_classifications.py:157-176`, the DEFERRED `regime_resolver=None`); the claims dereference resolver records `regime` as form-checked-only (`src/hermes/persistence/repositories.py:1928`); `target_regime` is validated as a free string (`src/hermes/research/programs.py:831-839`). This slice (Step 4 / S-R1) lands the FIRST implementable piece — the registry substrate itself — and nothing more.

## Constraints

- Pure, deterministic, stdlib-only: no model calls, no clock, no I/O, no persistence, no events, no new intents — the module is a pure function of (registry definition, snapshot).
- No migration, no schema change.
- **No behavior change to any existing module** — the `target_regime` wiring and the deferred-regime resolver activation are S-R2/R4, NOT this slice.
- Seed only what the live tree already assumes; **invent no axis entries**.
- No invariant weakened: single mutation path, append-only journal, no-authority discipline all untouched (the module writes nothing).

## Decisions

- **D1 — closed registry, verify-not-invent.** `REGISTRY` is a `frozenset` seeded with exactly the ICSS-v1 axis entries the live claims path already assumes — verified against the live assumptions, that is exactly one entry (`low-vol` under `ICSS-v1`). Adding an entry is a deliberate change to this module and its fixtures, mirroring the closed-vocabulary discipline (`SUPPORT_STATES`, `FailureClass`).
- **D2 — versioned reference type.** `RegimeRef(id, version)` with the canonical external tag form `VERSION:id` (`ICSS-v1:low-vol`, the exact form the claims path form-checks). A bare/unversioned form refuses with `UNVERSIONED_REGIME`; an unregistered (version, id) pair — including a known id under an unknown version — refuses with `UNREGISTERED_REGIME`. Identity is the versioned pair; determinism lives within a version.
- **D3 — classification-time snapshots only.** `RegimeSnapshot` exposes ONLY the `FalsificationRecord` field set (`project_id`, `hypothesis_ref`, `program_ref`, `falsifying_evidence_refs`) plus the claim context present at classification (`claim_context_tags`, canonicalized to sorted pairs). Post-outcome fields are structurally unrepresentable (slots; no such fields exist — the constructed attempt raises `TypeError`), so hindsight cannot reach membership evaluation.
- **D4 — deterministic, version-scoped membership.** `evaluate_regime(ref, snapshot)` resolves the ref against the closed registry (refusing first, fail-closed), then applies the definition's own pure predicate to the snapshot. Same (ref, snapshot) ⇒ the identical `RegimeEvaluation`, every call. A claim context that declares no `regime` tag at all yields `INDETERMINATE` — the honest fallback, never a guess.
- **D5 — closed verdict enum + decision-inertness.** `RegimeVerdict` is a closed three-member enum (`IN_REGIME` / `NOT_IN_REGIME` / `INDETERMINATE`); `RegimeEvaluation` is exactly (ref, verdict) — there is **no free-text reason field by construction**, so an INDETERMINATE cannot grow a rationale. Submitting an INDETERMINATE evaluation as authority refuses (`INDETERMINATE_NOT_AUTHORITY`): the registry classifies, it never decides a transition (determinism owns control; mirrors the `ConditionType.UNDETERMINED` / no-authority discipline).
- **D6 — identity excludes `notes`.** `RegimeDefinition` equality/hash is `(regime_id, version)` only; `notes` (and the predicate) are annotation, never identity — the `frozenset` registry dedupes on the versioned identity.
- **D7 — wiring deferred to S-R2/R4.** `target_regime` stays free-string-validated at `programs.py:831-839` and the DEFERRED resolver stances at `persistence/failure_classifications.py` / `repositories.py:1928` stand until S-R2/R4 wire them; this slice changes no existing module.

## Acceptance

All green (16 fixtures, `tests/test_regimes.py`; full suite + `ruff` + `pyright` clean at the slice commit):

1. REGISTRY seeds exactly `{("ICSS-v1", "low-vol")}` — the live-assumed axis entry, nothing invented.
2. `parse`/`resolve` round-trip on the live tag form `ICSS-v1:low-vol`.
3. Unknown id refused (`UNREGISTERED_REGIME`); known id under unknown version refused (`UNREGISTERED_REGIME`).
4. Bare/unversioned ref refused (`UNVERSIONED_REGIME`) across the malformed forms.
5. Membership evaluation deterministic within a version (repeated calls, rebuilt and reordered equal snapshots).
6. Post-outcome fields unrepresentable in `RegimeSnapshot` — the constructed attempt raises `TypeError`; the field set is exactly the classification-time surface.
7. `notes` excluded from identity (equality, hash, frozenset dedupe).
8. `RegimeVerdict` closed three-member enum (arbitrary values refuse); no-regime-declared ⇒ `INDETERMINATE`; INDETERMINATE submitted as authority refuses (`INDETERMINATE_NOT_AUTHORITY`); no free-text reason field exists on `RegimeEvaluation`; resolved verdicts pass the authority gate unchanged.

## Relation-to-baseline

No certified invariant is touched: no second write path, no persistence, no journal event, no gateway change, no LLM/model authority (the module is deterministic libraries only, consistent with `evaluation.py`-class substrates). This record operationalizes — without yet activating — the dereference carriers deferred in IDR-025/026 (claims `regime` dimension) and IDR-037 D5 (the failure-classification regime resolver); S-R2/R4 own the activation and must re-run the gates owning the touched surfaces at that point. Recorded debt (`hazards.py:137`) and the intentional-dependency census (ARCHITECTURE §3.10) are unchanged.

## Addendum (Step 4 / S-R2 wiring — the same decision, activated)

**Status:** Decided + implemented + tested (branch `step-4/s-r2`, from `step-4/s-r1-polfix@7fa79df`; local-only)
**Scope:** The wiring slice chartered after the S-R1 adversarial audit (PASS WITH CONDITIONS; audit record `docs/idr/step4_s_r1_adversarial_audit.md`). No new reviewer stance; the decisions above are unchanged — this addendum records their activation and the audit conditions' discharge.

### Decisions (activation of the decisions above)

- **A1 — the transition layer (charter item: transition substrate).** `RegimeTransition` records a classified regime resolution: the versioned `RegimeRef` (the (id, regime_ref) pair, frozen at classification), `timestamp`, `program_ref`, `hypothesis_ref`, the closed `TransitionResponse` (mirrors `RegimeVerdict` — three members, no free-text reason), `evidence_refs`, and the statically-typed `Literal["SIMULATED"]` provenance (`TransitionProvenance`), runtime-enforced in `__post_init__`: omitting it refuses with a `TypeError` (required, no default) and mistagging it refuses with `INVALID_TRANSITION_PROVENANCE` — an omission is not admitted with a default and a tag is not silently correctable. A transition's regime must be a REGISTERED pair (`UNREGISTERED_REGIME` otherwise).
- **A2 — citation rule.** A resolved response is cited, never asserted: non-empty `evidence_refs` required (`TRANSITION_EVIDENCE_REQUIRED` otherwise). The INDETERMINATE response stays decision-inert: it carries no evidence (extraneous evidence refuses, `EXTRANEOUS_TRANSITION_EVIDENCE`) and refuses as transition authority (`authoritative_transition` → `INDETERMINATE_NOT_AUTHORITY`), mirroring `authoritative_verdict`.
- **A3 — C1 discharge (audit condition C1 / F-3 / A2 precedent, BINDING).** The production path `derive_transition(regime, snapshot, ...)` has no caller-response/evaluation parameter — the response is RE-DERIVED from the registry + snapshot on every call (nothing to forge; a forged evaluation cannot be consumed because it cannot be passed). The audit's forged-evaluation attack dies at the boundary by construction; the claims and classification wiring points likewise re-check dims/verdicts with the real resolver bundle (never a hand-marked ADMITTED verdict). S-R4 consumers owe the same re-derivation stance.
- **A4 — discharge of audit condition C2 (F-1/F-2).** Typed-input refusals with codes landed in the substrate: a bare string in `falsifying_evidence_refs`/`evidence_refs` refuses (`MALFORMED_EVIDENCE_REFS` — char-split coercion eliminated); a bare string or non-pair item in `claim_context_tags` refuses (`MALFORMED_REGIME_CONTEXT`).
- **A5 — integration (a): target_regime registry validation.** `programs.py` no longer admits the free-string form: non-blank `target_regime` must reference a registered versioned tag (`UNVERSIONED_REGIME` for bare/unversioned forms; `UNREGISTERED_REGIME` for unregistered pairs; the retained blank guard fires first for blank strings). Identity still hashes the raw draft value. The `EMIT_PARALLEL_REGIME_PROGRAM` gateway path compiles through the same wiring (registered-tag discipline propagates end-to-end).
- **A6 — integration (b): the once-DEFERRED resolver wired.** `persistence/failure_classifications.py`'s `regime_resolver=None` stance is unwound: `_regime_resolver` resolves declared citations against the registry (registered tag resolves; bare/unregistered does not). The ENVIRONMENT_MISMATCH write-path refusal is lifted — the old documented asymmetry (substrate-admits/write-refuses) is replaced by the same registered-tag discipline live on both layers. The governance boundary is unchanged: the write path still re-runs the substrate with the REAL resolver bundle (a forged `claimed` classification for an unresolvable regime dies at the re-run BEFORE any claimed comparison — the boundary forge dies).
- **A7 — integration (c): claims regime dereference activated.** `repositories.py`'s `_make_resolver` resolves the `regime` dim live (registered tag dereferences; bare/unregistered is dangling at the write path — a hand-marked ADMITTED verdict cannot evade the dim re-check). `methodology` remains form-checked (ExperimentSpec is still a DEFERRED phase). No migration; no new tables.

### Constraints respected

No migration; deterministic (no model calls anywhere in the wiring); C1 at every wiring point (A3); no new write path (A6/A7 reuse the certified boundaries; the only writes remain the certified owners'); the `SUPPORT_STATES`/ladder vocabularies are untouched — `SIMULATED` is admissible ONLY as the transition layer's provenance literal (pinned by fixture).

### Acceptance (green at the slice commit; full suite + ruff + pyright clean)

1. `target_regime` registry validation: registered tag compiles; unregistered versioned (`ICSS-v1:high-vol`, `ICSS-v2:low-vol`) → `UNREGISTERED_REGIME`; bare/unversioned → `UNVERSIONED_REGIME`; blank → `INVALID_TARGET_REGIME`; ordinary-program Delta-0 row unchanged.

Transition: citation rule (unresolved response → `TRANSITION_EVIDENCE_REQUIRED`; cited → OK; determinism); provenance omission → `TypeError` and wrong-tag → `INVALID_TRANSITION_PROVENANCE`; `SIMULATED` omissible nowhere, mistaggable nowhere; INDETERMINATE-as-authority → `INDETERMINATE_NOT_AUTHORITY`; unregistered/bare refuse without freeze violation; the C1 signature pin (`evaluation=`/`response=` → `TypeError`).

4. Classification wiring: registered tag admits both layers; unregistered versioned and bare → refused both layers (nothing written); the boundary forge dies at the re-run.
